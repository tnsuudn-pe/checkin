# เช็คชื่อกิจกรรม คณะพลศึกษา มกช. วิทยาเขตอุดรธานี

หน้าเว็บสำหรับนักศึกษา (QR เช็คชื่อของฉัน) และผู้ตรวจ (สแกนเช็คชื่อ)
ข้อมูลทั้งหมดเก็บใน Google Sheet ของหน่วยงาน และตรวจสอบสิทธิ์ฝั่ง Apps Script — repository นี้มีเฉพาะหน้าเว็บ ไม่มีข้อมูลนักศึกษาหรือรหัสลับ

แก้ไฟล์แล้ว ให้เปลี่ยนค่า CACHE ใน sw.js ทุกครั้ง เพื่อให้มือถืออัปเดตหน้าใหม่
